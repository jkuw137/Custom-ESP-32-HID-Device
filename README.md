# USB HID Productivity Controller

A custom USB Human Interface Device (HID) designed to improve workflow efficiency by providing programmable buttons and rotary controls for common shortcuts and macros.

The project combines mechanical design, embedded systems, and electronics to produce a compact desktop controller inspired by commercial productivity devices while being entirely custom-designed.

This project involved:

- Designing the enclosure and internal mechanisms in Autodesk Fusion 
- Selecting and integrating switches, rotary encoders, and USB hardware
- Developing Arduino firmware implementing the USB HID protocol
- Iteratively refining the ergonomic layout through prototyping
- Manufacturing and assembling the final device using 3D printed components

## Engineering Overview

Commercial macro controllers often provide programmable shortcuts for creative workflows but can be expensive or lack customisation.

The objective of this project was to design and build a fully custom USB HID controller capable of functioning as a standard USB input device while providing an ergonomic interface tailored to user requirements.

The project required consideration of:

- Human factors and ergonomic button placement
- Compact internal packaging of electronics
- Structural design suitable for additive manufacturing
- Reliable switch mounting
- USB communication and firmware implementation
- Low latency and accessible controls


  ## Design Goals

- Develop a fully custom USB HID device
- Improve workflow efficiency through programmable controls
- Create an ergonomic handheld/desktop form factor
- Minimise component count while maintaining functionality
- Design for easy assembly and maintenance
